# Git 差异审阅

[返回目录](../Index.md)

> 适用产品版本：Silverwing Go 0.0.1　｜　代码核对日期：2026-10-19

任务详情的工作区卡片依次展示 **本地未提交 N**、**提交历史** 和远程状态。前两项可点击，本地未提交为 0 时仍可进入审阅；远程状态只用于展示，不触发操作。**整体差异** 模式保留在差异审阅页内部，不再作为卡片入口。差异页把当前工作区的文件变更组织成可浏览的文件树和内容面板；它用于查看与比较，不会替你提交、暂存、签出或推送代码。

## 选择审阅模式

- **整体差异**：比较当前分支相对配置主分支的已提交内容，默认右侧是当前 `HEAD`，因此不会把工作区未提交内容混进来。基线取主分支与当前 `HEAD` 的共同祖先。模块若单独配置了主分支，以模块配置为准，否则继承服务主分支；它不读取任务创建时的 `BaseRef`。本地必须已有该主分支引用，页面不会自动 `fetch`；缺失时按提示先更新仓库主分支，再重新打开审阅。
- **本地未提交**：比较 `HEAD` 与当前工作区，包括已暂存、未暂存及未跟踪文件。读取索引时使用隔离的临时索引，审阅不会把文件放入真实 Git 暂存区。
- **提交范围**：在主分支之后的提交中选一个提交，查看该次改动；或选择两端，查看连续父子链上的范围，页面会提示包含的范围。不要把范围预览等同于已将这些提交应用到主分支；如使用额外的模拟选项，结果仍只是审阅预览。

**包含本地未提交**是整体差异页中的额外开关，可把比较目标由 `HEAD` 切换到当前工作区；这时也会包含暂存、未暂存和未跟踪内容。切换模式或开关前先确认你要检查的是已提交差异还是本地编辑。

## 阅读文件树与内容

左侧列出变化文件，可在扁平列表和目录树间切换；选择文件后，右侧可查看**左右对比**或单侧内容。单侧标题会标出 `HEAD 内容`、`主分支基线` 或所选提交内容，审阅时核对标题、基线引用及当前服务/模块，避免把错误基线当成目标分支。**仅看改动**隐藏未变化上下文行；点 **查看全部** 恢复完整文件上下文。上一处/下一处用于在差异块间跳转。

例：虚构分支 `feature/REQ-DEMO-1001_order-refund-guard` 修改 `internal/refund/guard.go`。要检查尚未提交的三处改动，从卡片进入 **本地未提交**，确认文件树列出该文件，右侧显示暂存/未暂存/未跟踪变更，打开 **仅看改动** 后只剩新增与删除行；要审阅已经提交的分支改动则改用 **整体差异**，核对页面展示的主分支基线与 `HEAD`。**成功检查：**模式、仓库、模块、分支和左右侧标签符合预期，变更文件和差异块与待审内容相符。

查看全部文件内容不会改变工作区。二进制文件或超过预览上限的文件可能无法完整展示；遇到预览提示，应回到 IDE 或 Git 工具核验原文件，不要据此判断“没有改动”。页面刷新可重新读取当前状态；若工作区或主分支发生变化，重新读取后再进行审阅。
