# silverwing-product

Native Go / MyGO workspace for product colleagues. Branch: `release/snb-product`, derived from the completed `release/snb-qa` edition with identical features.

Keep tasks, requirements and comments, materials and text editing, optional material Git synchronization, Codex, Skills, plugins, MCP, AGENTS templates and all local utilities including port management.

Code repositories, Worktree, code Git operations, Tag, Genbu, production releases, IDE and Cursor integration remain removed.

Product uses its own app name, installer identities, data home (`~/silverwing-product`) and configuration discriminator (`edition: product`). It does not automatically import developer or QA tasks/configuration. Release tags use `product-vX.Y.Z`, assets use `silverwing-product-*`, and releases never become the repository latest release.

See [edition scope](docs/PRODUCT-EDITION.md), [release instructions](docs/RELEASE.md), and [Chinese documentation](README.md).
