# 外部工具

| 工具 | 用途 | 必需性 |
| --- | --- | --- |
| Git | 资料同步、Skill 和插件来源 | 对应能力启用时需要 |
| Meegle CLI | 需求、评论、身份与项目 | 连接需求时需要 |
| Codex | 打开任务、AI 命名、扩展和 MCP | 对应能力启用时需要 |
| 系统终端 | 外部 CLI 认证流程 | 认证需要时使用 |

配置入口在存储、任务、CLI、Codex 和代理设置中。代理可分别应用于 Codex、Git 和 Meegle，保留显式关闭选项。Git 不再用于业务代码仓库和工作区管理。

原生 PDF 与图表运行依赖随安装包一起分发，详见 [NATIVE-MEDIA.md](NATIVE-MEDIA.md)。
