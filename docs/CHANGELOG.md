# 版本变更记录

本项目采用 `vX.Y.Z` 标签发布桌面安装包。重大行为变化会在对应版本说明中记录；配置与任务数据 schema 的兼容边界以 [配置与使用](CONFIGURATION.md) 为准。

## 2.1.3

- 完善任务资料工作台，支持文档、PDF 连续阅读与缩放、图片查看、系统默认应用打开，以及资料编辑与文件操作。
- 需求全文统一缓存为 Markdown 和本地图片，支持后台缓存、主动刷新和复制需求文件；会话内复用已确认账户，减少打开本地需求时的等待。
- 需求详情新增只读评论，完整读取分页并按账户与需求缓存，刷新失败保留已有本地内容。
- 需求说明改为页内阅读，并合并为 `AGENTS.md`、`TASK-CONTEXT.md`、`TASK-RULES.md` 三个文件；保留草稿、模板、保存冲突和阅读位置，仅任务规则支持编辑。
- 设置中的“任务”与“AGENTS.md”独立分类，收窄设置导航，工作空间导航默认折叠；精简任务更多菜单。
- 更新透明背景的银翼图标，移除图标中的产品文字，并同步 Windows 与 macOS 图标资源。
- 修复 GitHub Release 同步飞书知识库时对 Wiki 根节点响应的字段解析，正确读取官方 CLI 返回的 `data.space_id`。

## 2.1.2

- GitHub 正式 Release 发布后自动同步到指定飞书知识库根页面：按 Tag 创建或更新子文档，写入自动 Release Notes，并附加 Windows 与 macOS 安装包文件卡片。
- 同一 Tag 重跑会安全刷新同名页面；出现多个同名 Tag 页面时中止同步，避免覆盖错误文档。

## 2.1.0

- 需求列表支持选择 Sprint（进行中与未开始），可保存默认 Sprint 团队空间；多个 Sprint 同时进行且空间内仅一个进行中时自动选中。
- 需求列表按工作项类型分组，支持任意 People 角色筛选，展示负责人节点估时与所选 Sprint 的个人估分；正文预览精简为工作项标题与角色行。
- 需求详情标题右侧新增“基于该需求创建研发任务”入口，创建弹窗自动预填需求链接、标题与分支，并按配置触发 AI 命名。
- 支持配置 Codex CLI 可执行文件路径（自动探测、手动配置与 PATH 回退），任务 AI 命名与 Codex 调用统一使用该 CLI。
- 设置页改为分类导航（基础、CLI、Git、网络代理、任务创建、分支命名、分组、Skill 来源、Codex 插件等），新增网络代理、任务创建与分支命名设置。
- Skills 页支持浏览与编辑本机 `~/.agents/skills`：列表、目录树与文件预览分栏，可刷新与卸载。
- 工作区模块主分支与测试 Tag 目标支持继承服务基线或自定义；提交历史可展开查看提交人与 SHA 详情并复制。
