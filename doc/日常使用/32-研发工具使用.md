# 研发工具使用

[返回目录](../Index.md)

> 适用产品版本：Silverwing Go 0.0.1　｜　代码核对日期：2026-10-19

左侧 **研发工具** 页面默认提供 JSON、日期时间和文本对比；**杀端口** 默认隐藏，可在 **设置 → 工具 → 研发工具** 打开对应显示开关。开关只控制工具入口显示，不会自动查询或结束进程。示例均为虚构输入；本篇不执行任何本机端口查询或进程结束操作。

![研发工具 JSON 页面示例](../assets/readme-developer-tools.png)

> 图片为 Windows 示例界面，输入内容仅用于演示工具布局。

## JSON

粘贴 JSON 后可点 **格式化**、**压缩**、**转义** 或 **反转义**。格式化会按层级排版，压缩会移除不必要空白；转义把原始文本编码为 JSON 字符串内容，反转义则解析转义内容。有效 JSON 会显示格式状态，语法错误可查看错误位置并定位到行列。编辑器支持查找、折叠嵌套对象/数组和节点复制；复杂文档可从折叠箭头逐层展开。单次工具文本输入上限为 **2 MiB**。

例：将 `{"orderId":42,"status":"paid"}` 粘贴到输入框并点 **格式化**，结果应出现缩进后的对象结构；点 **压缩** 后回到紧凑的一行。**成功检查：**状态显示 JSON 有效，字段和值没有丢失；故意删掉一个引号时，错误提示能定位到输入位置。

## 日期时间

日期时间页显示当前日期和秒、毫秒时间戳，点击结果可复制。输入框接受日期时间，以及 10 位秒时间戳、13 位毫秒时间戳，并按输入方向展示结果：输入日期时间时显示秒、毫秒时间戳，输入时间戳时显示转换后的日期时间；当前界面不单独展示 ISO 8601 结果字段。默认时区是 `Asia/Shanghai`；带偏移的 ISO 日期按输入偏移解析再转换显示。例：输入 `2026-10-09 12:30:00`，核对秒、毫秒值来自该时刻，再点击需要的结果复制。**成功检查：**转换方向和时区符合预期；日期输入对应的秒、毫秒时间戳相差 1000 倍，输入无效日期时显示错误。

## 文本对比

文本对比提供左右两个输入框。输入或粘贴文本后点击 **比较**，可查看差异块、上一处/下一处、差异复制；也可切换自动比较、折叠相同行、换边、软换行，并选择忽略大小写、行首尾空白或空行。查找可分别作用于两侧。例：左侧 `status=paid`、右侧 `status=refunded`，点击比较后应标出 `paid` 与 `refunded` 所在行；启用忽略大小写不会抹去这类值差异。**成功检查：**两侧内容与来源对应，差异位置、数量和忽略选项符合预期；每个输入按 2 MiB 上限控制。

## 杀端口：查询与高风险确认

启用工具显示后，进入 **研发工具 → 杀端口**。输入本机端口号（1–65535），明确点击 **查询** 或回车，页面才查询本机 TCP/UDP 占用；结果展示协议、状态、地址、进程、PID 和启动时间。TCP、UDP 显示开关只筛选结果表，不会执行结束操作。例：对虚构端口 `5173` 查询后，如果列表出现某个开发服务器，先核对地址、进程名、PID 和启动时间；只切换 TCP/UDP 显示开关以缩小列表，不代表进程已停止。

只有在确认目标进程可结束时，才选中结果点 **结束…**，检查确认面板中的进程身份，再由操作者显式点 **确认结束**。应用会在结束前复核进程身份，明确拒绝 PID 0、Silverwing 自身 PID，以及缺少或无法解析启动时间的目标；它没有按“系统进程”类别统一禁止结束，实际操作还受操作系统权限限制。先核对进程用途，不要把按钮可用理解为结束该进程不会影响系统。完成后看页面结果并重新查询确认端口状态。**成功检查：**查询结果与预期监听进程匹配；若确实执行了结束，结果明确显示进程退出或端口被其他进程重新占用。仅看到页签、查询结果或确认窗口，不等于进程已结束。
