# Silverwing 知识库

Silverwing 是基于 Go 与 MyGO 的原生多仓库研发工作台。这份知识库包含 **32 篇正文**，覆盖入门、日常使用、AI 工具、外部集成、配置数据、技术架构和开发维护。

![Silverwing 任务工作台与 Git 审阅示例](assets/readme-banner-light.png)

> [!info] 适用版本
> 内容按 **2026-10-19 的 Go / MyGO 版代码**整理，源码产品版本为 **0.0.1**。安装程序的版本请在“设置 → 系统 → 关于”核对。旧 Kotlin / Compose 版的路径、依赖和功能不能直接套用。

## 推荐阅读路线

- **第一次使用**：02 安装 → 03 配置 → 04 接入 Meegle → 05 创建任务。
- **先体验本地功能**：02 安装 → 03 配置；可先使用仓库管理和 JSON、日期时间、文本对比工具。
- **日常开发**：09 仓库服务 → 06 任务工作区 → 10 Git 审阅 → 11 任务资料 → 12 Tag 交付。
- **使用 AI 工具**：13 工具配置 → 14 上下文与模板 → 15 Skills → 16 插件与 MCP。
- **迁移和排障**：20 数据目录 → 21 备份迁移 → 22 CLI 环境 → 08 故障排查。
- **参与开发**：07 架构总览 → 23 至 27 架构专题 → 28 本地开发 → 29 测试 → 30 发布。

现有 Windows 界面截图来自源码仓库的 `docs/assets/`，使用示例数据。新绘制的流程图、目录图和架构图均注明“示意”，用于解释当前实现，不代表额外存在的界面或功能。文章使用 PNG 配图，便于在 Silverwing 资料预览和常见 Markdown 阅读器中显示；`assets/` 同时保留对应 SVG 作为可编辑图源。所有配图通过相对链接引用，离线也可阅读。

## 代码与维护依据

知识库随源码保存在仓库根目录的 `doc/`，各篇末尾的源码索引均相对于仓库根目录。原有 `docs/` 中的工程说明继续保留，供组件实现与打包细节查询。

- 产品版本与模型：`internal/domain/models.go`。
- 功能入口和说明：[项目 README](../README.md)。
- 架构边界：[工程架构说明](../docs/ARCHITECTURE.md)。
- 原生打包与资源：[构建与发布](../docs/RELEASE.md)、[原生媒体](../docs/NATIVE-MEDIA.md)。
- 编辑和文件树边界：[TextEditor 与 FileTree](../docs/TEXT-EDITOR-AND-FILE-TREE.md)。

更新知识库时，优先核对界面标签、任务创建入口、数据目录、CLI 调用和归档删除行为，再同步调整受影响的示例与图片。
