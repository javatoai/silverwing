# 外部命令运行边界

2026-10-20：检查 SW 运行时的外部命令入口，修复 macOS 桌面环境与 CLI 设置检测、业务调用之间的差异。

## 命令准备与执行

`internal/executable` 负责命令发现、macOS 登录 PATH 缓存和固定系统工具路径。`internal/commandruntime` 合并工具默认环境、按目标配置的代理和诊断脱敏。业务调用设置参数、工作目录及专用环境，最后由 `internal/process` 执行、限时、取消和清理进程树。

- 显式命令优先；macOS 子进程 PATH 顺序为命令目录、登录 PATH、原进程 PATH，去重后使用。裸命令在该 PATH 中解析，不把用户命令拼接进 shell。
- 登录环境只获取 PATH；不导入整套 shell 环境，不修改 SW 进程的全局环境。并发探测共享结果，取消与强制刷新有代次保护。
- 启用代理的 CLI 使用对应目标的代理和 NO_PROXY；未选择的目标移除继承代理。Bootstrap 保留原有代理继承行为。
- Git 隔离索引、Codex 独立 HOME 等操作专用环境最后叠加。外部工具执行不进入界面绘制循环。

## 任务创建结果

清单保存、返回与工具启动比较使用同一规范化表示，空列表的 `nil`/`[]` 差异不构成并发修改；真实字段变化和任务重建仍拒绝启动。成功创建后的资料或工具失败独立提示，保留任务身份和已有重试入口，不重新执行创建事务。

目录重名展示已有建议，由用户修改文件夹名。后台检查绑定表单、名称、根目录和应用 HOME，限制并发并合并快速输入；预检和最终锁内检查仍拒绝已有文件、目录和符号链接。

## 验证边界

替身命令验证环境、代理、命名隔离和失败分流；macOS 专项测试覆盖精简 PATH 下启动命令及其 Node shebang。Windows 可进行 Darwin 测试程序的交叉编译，但不能替代 macOS 桌面真机验收。首次资料准备验收必须使用新目录，已有目录的 READY 不能证明远端 CLI 链路正常。
