# 任务资料使用

[返回目录](../Index.md)

> 适用产品版本：Silverwing Go 0.0.1　｜　代码核对日期：2026-10-19

任务详情中的 **任务资料** 页签浏览当前任务关联的资料目录。资料根目录可位于任务根目录之外；界面显示的文件树只代表当前资料根下可访问的内容，不代表 Silverwing 会把资料复制到工作区。单击文件可在右侧预览，双击可固定为打开页签；点目录可展开或收起。工具栏还提供名称/修改时间排序、快速打开、全文搜索以及新建、导入和文件操作入口。执行任何移动、重命名或删除前，先核对选中路径。

## 预览与编辑

- **Markdown**：默认以排版后的阅读视图显示；菜单中的 **查看 Markdown 原文** 可查看源文本，**返回 Markdown 预览** 回到排版视图。两种模式都只读，资料 Markdown 不提供编辑和保存入口。不要将源码中的其他 Markdown 编辑能力误认为资料页可以写入。
- **普通文本**：TXT、SQL 与支持的代码文件可直接进入文本编辑器。JSON、CSV 默认提供结构化预览，并可用 **编辑源码** 切换到文本编辑；CSV 预览可查看表格内容，格式异常时可回到源码检查。PDF 和常见图片格式显示为原生预览；暂不支持的文件类型会提示改用系统应用打开。
- **链接**：Markdown 中的 HTTP、HTTPS、mailto 链接交由系统打开；相对链接仅在当前任务资料根目录内解析。资料根之外的相对路径和不支持的链接目标会被拒绝。

例：在 `materials/REQ-DEMO-1001/` 中选中 `acceptance.csv`，单击预览表格后点击 **编辑源码**，把某个验收项的 `todo` 改为 `done`。普通文本会延迟自动保存，也可按 `Ctrl+S`；保存时应用会检查磁盘版本。如果提示外部修改，先比较双方内容，再决定 **使用磁盘版本**（丢弃本地草稿）或在确认后 **覆盖磁盘版本**。保存成功后，编辑器显示已保存状态；重新打开文件仍能看到刚才的修改。

## 大小与路径边界

普通资料文本的读取和最终编码保存上限为 **3 MiB（3 × 1024 × 1024 字节，含 UTF-8 BOM）**；超限内容不能按普通文本编辑保存。可编辑文本要求有效 UTF-8 且不含 NUL 字符；不兼容编码会进入只读处理。语法高亮、JSON/CSV 预览只改变显示，不会替代保存时的原始文本。

所有资料文件操作限定在已配置的资料根目录内。路径校验会拒绝越界路径、`.git` 路径段、符号链接或 Windows 重解析点；目录过深或无法访问的内容可能不会列出。不要把资料面板当成任意磁盘文件浏览器，也不要通过相对链接绕过目录范围。

**成功检查：**确认任务和资料根目录正确；预览类型与扩展名相符；Markdown 只读；普通文本保存后无错误，磁盘版本与预期一致；未触发 3 MiB 上限或路径安全提示。若页面提示文件冲突、超限或格式不支持，应保留原文件并按提示处理，不要重复覆盖。
